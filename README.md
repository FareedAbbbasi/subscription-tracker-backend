# Subscription Tracker Backend (Node.js + Express)

A backend project built to strengthen my backend development skills by implementing
a real-world **subscription tracking system**.

This project was implemented by following a backend-focused course, with full hands-on
coding and understanding of the core concepts.

## 🚀 Features
- User authentication & authorization (JWT)
- Subscription management
- Reminder workflow for renewals
- Email notifications
- Centralized error handling
- MongoDB with Mongoose
- Secure API architecture
- VPS deployment

## 🛠 Tech Stack
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- Email service
- Arcjet (security)

## 📚 What I Learned
- Backend architecture & API design
- Authentication vs Authorization
- Structuring scalable Express apps
- Subscription-based business logic
- Error handling best practices
- Email workflows
- Deployment on VPS

## 📌 Notes
This project was built for **learning purposes** and focuses on backend concepts
and best practices.
